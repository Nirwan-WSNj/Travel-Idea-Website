# GitHub Pages Setup

This project is a static HTML, CSS, and JavaScript website, so it can be hosted with GitHub Pages.

## Recommended setup

1. Open the repository on GitHub.
2. Go to Settings.
3. Open Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch.
6. Select the root folder.
7. Save.

After GitHub finishes deployment, the website will be available at a GitHub Pages URL similar to:

```text
https://nirwan-wsnj.github.io/Travel-Idea-Website/
```

## Notes

Because this repository currently uses `Home.html` as the main page instead of `index.html`, the direct home page URL may be:

```text
https://nirwan-wsnj.github.io/Travel-Idea-Website/Home.html
```

A future improvement is to rename `Home.html` to `index.html` and update links carefully.
